# MIRPI Learning in Connect Bro

## Основной принцип

Connect Bro отделяет **память опыта** от **весов модели**.

MIRPI учится в процессе работы так:

1. получает задачу;
2. наблюдает ответы DeepSeek/ChatGPT и результаты локальных инструментов;
3. выделяет код, гипотезы, ошибки и решения;
4. сохраняет опыт в журнале;
5. формирует вывод и уровень уверенности;
6. использует накопленную память в следующих задачах;
7. после накопления проверенных примеров данные могут быть превращены в обучающий набор.

## Почему так

Такой подход позволяет:

- видеть, чему MIRPI научился;
- удалить ошибочный опыт;
- воспроизводить ход решения;
- не портить модель одним неудачным экспериментом;
- сравнивать старую и новую версии модели перед обновлением.

## Цикл

```text
QUESTION
   ↓
CONTEXT
   ↓
HYPOTHESIS
   ↓
AI RESPONSES
   ↓
CODE / EXPERIMENT
   ↓
TEST / OBSERVATION
   ↓
RESULT
   ↓
LEARNING RECORD
   ↓
MIRPI MEMORY
   ↓
NEXT QUESTION
```

## Будущие уровни доказательности

E0 идея → E1 предположение → E2 литература → E3 аналитический расчёт → E4 цифровая симуляция → E5 воспроизводимый цифровой эксперимент → E6 физический эксперимент → E7 независимое подтверждение → E8 практическое применение.

Уверенность (`confidence`) хранится отдельно от уровня доказательности.
