# Connect Bro

Локальный macOS-центр координации DeepSeek, ChatGPT и MIRPI.

## Цель

Connect Bro создаётся как безопасный оркестратор инженерной работы: человек ставит задачу, AI-агенты обмениваются результатами, код сохраняется, а MIRPI накапливает проверенный опыт.

## Принцип обучения MIRPI

Каждое событие рабочего процесса рассматривается как опыт:

`задача → ответ → код/идея → проверка → результат → вывод → память`

Важно: MIRPI не изменяет веса модели после каждого сообщения. На первом этапе он учится через структурированную память, журнал экспериментов и подтверждённые знания. Позже эти данные могут стать датасетом для контролируемого обучения.

## MVP 0.1

- чистый Swift + SwiftUI;
- три AI-панели: DeepSeek, ChatGPT, MIRPI;
- единый поток сообщений;
- очередь задач;
- извлечение кода из Markdown;
- локальный журнал опыта MIRPI;
- рабочая папка проекта;
- безопасный режим: автоматическая запись в проект отключена по умолчанию;
- архитектура транспортов, чтобы подключать web/local/API способы связи без переписывания ядра.

## Структура

- `Sources/ConnectBro/Core` — ядро и шина сообщений;
- `Sources/ConnectBro/Agents` — адаптеры AI;
- `Sources/ConnectBro/Code` — извлечение кода;
- `Sources/ConnectBro/Memory` — память MIRPI;
- `Sources/ConnectBro/Workspace` — рабочее пространство и журнал;
- `Sources/ConnectBro/UI` — интерфейс.

## Сборка

Требуется macOS с Swift 6 и Xcode/Swift Package Manager.

```bash
swift build
swift test
swift run
```

## Безопасность

Connect Bro не должен автоматически выполнять произвольный код, полученный от внешнего AI. Изменения проходят через журнал, diff и политику подтверждения.
